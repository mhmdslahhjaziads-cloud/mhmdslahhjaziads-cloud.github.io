Campaign links and contact measurement

Use the same naming rules for each portfolio campaign so GA4 acquisition reports can compare sources clearly. Keep all values lowercase and use underscores inside a value.

ParameterMeaningExamples

Never put names, email addresses, phone numbers, message text, client identities or other personal data in UTM parameters. Do not tag internal links: it can distort acquisition attribution. Preserve the existing query when switching languages.

What success means

The primary website outcome is a contact intent: a visitor clicks WhatsApp or email. The existing GA4 contact event has contact_method set to whatsapp or email. A click does not establish that the visitor sent a message or became a lead. Confirm qualified inquiries separately using actual conversations.

EventUse
contactPrimary contact intent; mark this event as a GA4 key event after verifying receipt in the property.
whatsapp_click, email_clickChannel diagnostics. These accompany the contact event; do not count them again as separate conversions.
cv_download_clickSecondary engagement: a click to request the CV, not confirmation of download completion.
contact_section_view, talk_button_click, scroll_depthFunnel context; avoid treating each as a lead.
linkedin_click, brand_website_click, brands_show_more_clickOther engagement and navigation diagnostics.

Simple reporting view

In GA4, use session source/medium and session campaign as the acquisition dimensions. Compare sessions, engaged sessions, users who trigger contact, and contact key events. Keep CV clicks in a separate engagement column. Break contact down by contact_method after registering that event-scoped custom dimension. Show device category and Arabic/English page path as secondary breakdowns. If calculating a contact session rate, divide sessions containing contact intent by total sessions for the same period and segment.
